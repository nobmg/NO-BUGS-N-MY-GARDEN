# Business Credit, Filing & Funding Command Center (Launch Ready)

Production-style local-first SPA for multi-company operations.

## Launch-ready capabilities
- Accounting ledger with search/filter and KPI dashboard
- DUNS + credit profile validation (format and score constraints)
- Tradeline + credit account tracking with utilization insights
- UCC1 statements, contracts, and fiduciary filing tracker
- Funding / loan / grant qualification tracking with requirement checks
- Auto-loan approval simulator (payment, DSCR, approval status)
- Strategy generators: qualification plan + "be your own bank" actions
- Operational controls: export backup, import backup, template download, clear-all reset
- Last-saved timestamp and inline notifications for user actions

## Run locally
```bash
python3 -m http.server 8000
```
Open `http://localhost:8000`.
